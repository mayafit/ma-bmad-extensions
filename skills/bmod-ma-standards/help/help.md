# ma-standards knowledge

This document covers the skills of the `ma-standards` module: what each one gives the user and when to recommend it.

## Skills

- `ma-standards-apply`: writes the `ma-standards` instruction block into the project's instruction files (`AGENTS.md`, `CLAUDE.md`, `.clinerules`, `.roomodes`, `.github/copilot-instructions.md`) and removes it with `remove`. Recommend it when the user wants the organisation's standards applied to the coding tools of a project.
