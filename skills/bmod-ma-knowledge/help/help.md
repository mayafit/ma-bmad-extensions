# ma-knowledge knowledge

This document covers the skills of the `ma-knowledge` module: what each one gives the user and when to recommend it.

## Skills

- `ma-knowledge-atlas`: generates the Knowledge Atlas, a self-contained HTML site of the initiative store, into `atlas_output` (empty: `{output_folder}/knowledge-atlas`). Recommend it when the user wants to browse or share the project's initiatives, epics and stories with their status.
